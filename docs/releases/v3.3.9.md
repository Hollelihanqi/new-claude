修复当前版本 ChatGPT 客户端无法识别独立目录能力、导致多开被阻止的问题。

- 客户端改用 `early-bootstrap-*` 启动分块后，检测不再依赖固定文件名前缀，改为按客户端实际构建目录检查启动脚本内容。
- 检查覆盖全部启动分块，避免能力代码位于后续分块时漏检；同时对分块数量（最多 128 个）和总大小（最多 64 MiB）设置上限，超限时停止检测并提示更新 PathMux，不冒险放行。
- 未能确认独立目录能力时的提示改为可操作指引：刷新或重新选择客户端；若客户端刚更新，请检查 PathMux 更新。
- Windows 与 macOS 共用同一套客户端解析逻辑，两个平台的检测行为保持一致。

验证边界：本地完整回归及 Windows/macOS 自动测试覆盖本版本；仅在双平台安装包构建、更新签名和国内镜像核验通过后公开。这些检查不代表双平台桌面实机端到端验收。

安装包：macOS 使用通用 .dmg，Windows 使用 .msi 或 .exe。保留国内更新源和 GitHub 备用地址，安装说明见仓库 README。
