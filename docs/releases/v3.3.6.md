本次修复「复制会话」中暴露的标题污染、列表难读和大记录无法复制三类问题。

- 会话标题、摘要和右侧预览不再被客户端内部消息污染。Codex 会把 `<external_codex_apps_open_page>`、`<recommended_plugins>`、`<in-app-browser-context>`、审批记录里的 `[N] tool exec result:` 等内部内容写成“用户消息”，旧版本把它当成第一句提问。现在这些合成记录会被过滤，标题显示真实提问。
- 会话列表按项目分组，组内超过 5 条折叠为「展开显示」；每行只保留单行标题和相对时间，摘要与标题相同时不再重复。父会话内部的 subagent / guardian 会话不再单独列出，与 ChatGPT 客户端的侧栏保持一致。
- 复制按钮不可用时，旁边直接说明原因（未选来源/目标、未勾选、哪条不能复制及原因）；「对话预览」增加只读说明。
- 取消单条 32 MB 上限：复制链路改为逐行流式读写，单条上限提升到 512 MB，大记录不再整份载入内存。

补充了标题过滤、内部会话隐藏、项目分组、流式迁移与大会话上限的回归测试，覆盖 Windows 与 macOS 两种客户端布局。

验证边界：本地完整回归及 Windows/macOS 自动测试覆盖本版本；发布流程仅在双平台安装包构建、更新签名和国内镜像核验通过后公开。本机仅用 Windows 真实数据验证了列表、预览和一次 20.5 MB（含 12 张图片）的真实复制；超过 32 MB 的记录完成了预览、构建与 stage 写入验证，但受来源会话本地图片已被系统清理影响，未完成一次完整的超限真实复制。
