修复 v3.3.12 在 macOS 上编译失败的问题，并保留 Windows 多开沙箱凭证修复。

- 根因：`seed_markers` 被限定为 Windows 实现，但它的单元测试在 macOS 上同样参与编译，导致 `cannot find function seed_markers in this scope`。v3.3.12 因此未通过 macOS 测试，未公开发布。
- 修复：`seed_markers` 是纯文件逻辑，改为双平台可编译；Windows 生产路径保持不变，macOS 单元测试也能覆盖该逻辑。Windows 上不产生行为变化。
- v3.3.12 的 Windows 沙箱凭证修复保持有效：启动前收敛全部实例和默认 `~/.codex` 的沙箱凭证，新建实例继承现有凭证与 setup marker，避免任一实例重新 setup 时改掉全机共享密码。
- 上游 provisioning 拒绝 reparse point，因此继续使用真实目录，不使用 junction 或硬链接。

验证边界：本次修复由 Windows 本地完整回归和 Windows/macOS 自动测试共同覆盖；仅在双平台安装包构建、更新签名和产物核验全部通过后公开。

安装包：macOS 使用通用 .dmg，Windows 使用 .msi 或 .exe。保留国内更新源和 GitHub 备用地址，安装说明见仓库 README。
