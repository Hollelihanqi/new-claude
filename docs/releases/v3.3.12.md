修复 Windows 多开实例之间沙箱凭证不一致，导致 ChatGPT 显示「Windows 设置未完成 / 设置已停止」的问题。

- 根因：Windows 沙箱只创建一对全机共用的本地账号，但 ChatGPT 客户端把账号密码按 `CODEX_HOME` 各存一份。任一实例重新执行 setup（新建实例、客户端版本更新、手动「重新设置」）都会改掉全局密码，却只更新自己那份，其余实例继续使用旧密码，登录返回 1326。
- 修复：PathMux 在客户端启动前检查全部实例和默认 `~/.codex` 的凭证，找出唯一仍能登录的那份，以原子写入方式同步到其余实例；所有副本一致时跳过解密与登录验证，不产生额外开销。
- 新建实例会继承现有有效凭证和 setup marker，首次启动不再触发重建账号、不再改掉其他实例的密码。
- 上游 provisioning 明确拒绝 reparse point，因此本版本不使用 junction 或硬链接，保留每个实例的真实目录，避免破坏官方 setup。
- 仅影响 Windows；macOS 沙箱使用 Seatbelt、不创建本地账号，无等价逻辑。

验证边界：本地完整回归、Windows 真机启动与实例启动链路、`--sync` 损坏恢复测试均已执行；仅在 Windows/macOS 自动测试、双平台安装包构建、更新签名和产物核验全部通过后公开。

安装包：macOS 使用通用 .dmg，Windows 使用 .msi 或 .exe。保留国内更新源和 GitHub 备用地址，安装说明见仓库 README。
