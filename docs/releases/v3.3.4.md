ChatGPT 多开实例卡片现在会显示账号名与邮箱，例如「kele · 1401009231@qq.com」。账号名从该实例本地保存的账号凭据中读取，与邮箱同源；账号未设置名称或凭据中没有名称时，自动回退为只显示邮箱。API 模式仍只显示「API 模式」，不会展示残留的账号信息。

账号名仅用于本地展示，不参与鉴权。接口返回结构与旧版本兼容：没有名称的账号不会新增字段，无需迁移。

补充账号名解析、缺失回退和 API 模式隔离的回归测试，覆盖 Windows 与 macOS 两种客户端布局。

验证边界：本地完整回归及 Windows/macOS 自动测试覆盖本版本；发布流程仅在双平台安装包构建、更新签名和国内镜像核验通过后公开。这些检查不代表真实 ChatGPT 账号切换及双平台桌面实机端到端验收。
