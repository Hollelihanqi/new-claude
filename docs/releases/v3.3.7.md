修复「复制会话」中点击「刷新记录」时整页闪动的问题。

刷新时不再清空并重建会话列表、右侧预览、搜索词、滚动位置和分组展开状态；按钮改为显示「刷新中…」并旋转左侧图标，同时禁用避免重复点击。刷新完成后静默更新列表，已勾选或正在预览的会话在仍然存在时保持不变。

补充了刷新期间列表保持可见、按钮 loading 状态的回归测试。

验证边界：本地完整回归及 Windows/macOS 自动测试覆盖本版本；发布流程仅在双平台安装包构建、更新签名和国内镜像核验通过后公开。本机在 Windows dev 版用真实数据（人为延迟 1.5 秒）验证了刷新期间无 DOM 行移除、预览保持、按钮 loading；macOS 未做真机 UI 验证。
