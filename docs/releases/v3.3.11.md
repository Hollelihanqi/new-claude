修复跨模型服务复制后无法继续对话的问题，并让 API 模式的推理强度选择与官方模型目录保持一致。

- 复制会话时会按目标实例的当前配置改写模型提供方：会话头、`thread_settings.model_provider_id` 和每一轮 `turn_context.model` 都改为目标 provider 与目标默认模型，避免客户端因 provider 或模型不匹配拒绝继续。
- 账号实例之间的复制保持原样，不修改 provider、模型或历史设置；只有来源与目标 provider 不同时才改路由。
- 复制中断时显示真实原因，不再被「复制已暂停」的通用提示覆盖。
- API 模式的模型目录改为与官方一致的 `low / medium / high / xhigh / max / ultra`，默认 `high`；客户端按自身默认规则显示（默认隐藏 `max`）。
- 已有 API 实例的旧模型目录会在读取实例状态或启动客户端时自动升级，不需要重新保存 API 配置。
- Windows 与 macOS 共用同一套逻辑与回归测试。

验证边界：本地完整回归及 Windows/macOS 自动测试覆盖本版本；仅在双平台安装包构建、更新签名和国内镜像核验通过后公开。这些检查不代表双平台桌面实机端到端验收。

安装包：macOS 使用通用 .dmg，Windows 使用 .msi 或 .exe。保留国内更新源和 GitHub 备用地址，安装说明见仓库 README。
