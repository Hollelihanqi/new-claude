## 凭证与配置兼容

Windows 保留旧 PowerShell ConvertFrom-SecureString 的 DPAPI 十六进制格式，生成的终端脚本仍可读取新凭证；原生接口也能读取旧凭证。已用非真实测试 Key 验证双向兼容，并覆盖 Unicode Key 原生往返。

macOS 保留原 service/account 命名，更新使用原生接口，不先删除旧凭证。已增加临时钥匙串测试与 CI 步骤，实际结果仍需 macOS 验证。

实例设置的 revision 已由修改时间数字改为内容哈希字符串，并明确用 missing 表示文件不存在。前后端接口同步更新，不修改用户 settings.json 的格式。此修复保护管理中心与自身后台同步之间的写入；不承诺可以锁住不遵守该锁的外部编辑器。

## 证书行为

按用户要求保留现有证书行为：不要求所有环境上传证书，不修改跳过校验设置，不改变网关通信的证书策略。有些环境需要自定义证书，有些不需要；后续如调整证书设置，应按环境区分。

## 构建体积

修复前生产构建首屏 JavaScript 约 1,767 kB；修复后根据 dist/index.html 的脚本及 modulepreload 链接汇总，首屏 JavaScript 为 470,412 字节，减少约 73%。此数字包含首屏共享模块，不只是入口文件大小。

首屏 JavaScript 的 gzip 合计由约 569 kB 降至约 156 kB。图表页面约 587 kB，进入洞察页面时才加载，仍会触发单个分块超过 500 kB 的构建提示。这里验证的是产物体积，没有宣称真实启动耗时降低相同比例。
