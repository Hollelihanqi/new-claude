# 插件交互修正与测试清理

按用户明确要求直接修改：单元测试覆盖功能业务逻辑，页面通过浏览器验证，不新增 UI 单元测试。

## 插件页面的七项修正

| 问题 | 修改结果 |
| --- | --- |
| 操作一行后其他行变灰 | 仅锁定该环境的该插件；其他行可继续提交，后台依次写入，防止并发配置冲突。重复提交同一插件不会重复执行。 |
| 刷新时右侧闪动 | 保留原列表，不切换整页 loading、不替换按钮结构、不全局禁用；只旋转固定尺寸刷新图标。 |
| 更新被判失败 | 安装/更新后的启停步骤先读取真实状态，已经达到目标状态则跳过，不重复调用启用/停用。仍保留更新返回的重启提示。 |
| 更新连续出现两个弹框 | 确认、执行、成功或失败、重试均在同一个中间 Modal 内完成；点击状态栏“查看结果”才打开结果抽屉。 |
| 空的可添加区域冗余 | 可添加数量为零时整块不显示，删除列表底部说明。 |
| 列表标题和搜索冗余 | 删除左上“插件”标题和搜索，已安装标题与操作按钮放在同一行。 |
| 提示独占一行导致跳动 | 执行、刷新、错误、完成提示及查看结果入口合并进“当前管理”栏，不再插入独立进度条或弹出通知。 |

多个执行记录可从结果抽屉切换查看。重试复用原执行记录，成功后清除对应失败状态，不覆盖其他未处理记录。
